图片转 GIF 纯本地 · 不上传

选几张图 → 排好顺序 → 调速度 → 生成下载。全程在浏览器里完成，图片不会离开你的设备。

1选图片

点这里选图，或把图片拖进来 支持 JPG / PNG / WebP / BMP / GIF 首帧 · 可多选、可分次添加

2排顺序

用 ↑ ↓ 调整顺序，电脑上也支持直接拖动。第 1 张决定画面比例，其他图等比居中、不拉伸。

3设置

不勾「保留透明」时，透明区域会填成上面的背景色。GIF 只有 256 色，照片类素材建议宽度 480 左右；超过 30 帧在手机上会慢一些。

✓做好了

下载 GIF

手机上如果点下载没反应，长按预览图选择「保存图片」。
